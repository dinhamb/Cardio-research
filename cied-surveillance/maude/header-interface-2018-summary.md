# 2018 header-interface calibration summary

The 2018 bulk pull produced:
- 2,476 candidate device rows,
- 2,475 unique MDR keys,
- 2,271 exact-narrative event groups.

Only 33 exact groups carry spring-contact language, but the clinical specificity is high.

## Advisory-gap evidence

A DYNAGEN D151 + Medtronic Sprint Quattro 6947 report (MDR 7868108) is particularly informative. It documents recurrent >3000-ohm RV pacing-impedance alerts with clean stored EGMs and Boston Technical Support attributing the pattern to a competitor-lead spring-contact issue.

The reporter also documented that:
- there was **no safety alert/advisory specifically for this issue**, and
- Boston Technical Support indicated the phenomenon was already known.

This supports modelling the 2017 MV advisory and the broader transient-impedance/spring-contact problem as overlapping but non-identical safety signals.

## Strong negative control

MDR 7978101 initially presented as recurrent high shock impedance in a DYNAGEN D151 system. Revision identified a **loose high-voltage setscrew**, and tightening restored normal DFT measurements.

This is an important reminder that intermittent high-voltage impedance requires mechanism adjudication rather than automatic assignment to spring contact.

## DF-1 relevance

DYNAGEN D151 uses an RV IS-1/DF-1 connection. The 2018 hybrid spring-contact cases therefore provide a useful pre-DF4/comparator phenotype when later assessing Boston RV-DF4 shock-impedance candidates.
