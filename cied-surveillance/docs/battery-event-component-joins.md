# Battery event-to-component joins

The current-year MAUDE cell-mechanism calibration contains 42 deduplicated event groups.

At present, **7 events can be responsibly joined to an exact supplier/cell family using primary FDA evidence**: the Fortify Assura / Quadra Assura lithium-cluster events map to the Greatbatch QHR2850 battery platform.

FDA records describe the QHR2850 as:
- lithium anode,
- blended SVO + CFx cathode,
- high-rate battery architecture,
- connected to the device hybrid via gold-plated battery posts into spring connectors.

FDA's 2017 warning letter explicitly discusses Greatbatch QHR2850 lithium-cluster bridging and states the battery process was used across Unify, Fortify, Assura and Quadra ICD/CRT-D families.

## Deliberate unresolved joins

Do **not** yet assign exact contemporary cell models/suppliers to:
- Medtronic Visia/Evera/Claria/Viva lithium-plating events,
- Boston RESONATE/DYNAGEN/VIGILANT latent-leakage/internal-short events,
- Biotronik Rivacor/Acticor/Intica/Effecta/Etrinsa/Ecuro events.

Historical manufacturer/cell mappings exist, but that does not prove the same cell supplier/model in these later product generations.

This is an important constraint: the engineering spine is allowed to remain sparse rather than turn chemistry similarity into a false shared-component claim.
